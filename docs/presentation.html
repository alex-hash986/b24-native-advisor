Где растёт стоимость внедрения

  1. Разработка

    Внешние боты и микросервисы

    Даже для распределения лидов заказывают отдельный бот, пропуская проверку очередей CRM-форм. К разработке добавляется сопровождение.

  2. Внедрение

    План без слепка портала

    Предложенные стадии, поля и воронки могут расходиться с тем, что уже настроено. Расхождения приходится выяснять в ходе внедрения.

  3. Рекомендации

    Непроверенные ответы LLM

    Без привязки к порталу и официальной справке модель может выдумать настройку или сослаться на неприменимый источник.

Кастом, API или интеграция рассматриваются при подтверждённом разрыве в штатных возможностях.

Как проверяется штатный план

  1. 01 · Слепок

    Read-only аудит

    Пять разрешённых REST-методов читают метаданные CRM. Единый диспетчер ограничивает частоту до 2 запросов в секунду на портал.

  2. 02 · Поиск

    Официальная справка

    50 фрагментов справки и REST-документации. По умолчанию поиск принимает источники, проверенные за последние 30 дней.

  3. 03 · Анализ

    FAST и SMART

    FAST классифицирует запрос, SMART сопоставляет доказательства. Валидатор проверяет ID цитат и наблюдений, отклоняет URL в тексте модели.

  4. 04 · Решение

    План и ручная сверка

    При пробелах видимости API свежая применимая справка может обосновать условный план. Настройки по чек-листу сверяет администратор.

При недостатке доказательств советник фиксирует причину и передаёт вопрос на ручную проверку.
